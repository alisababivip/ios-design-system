# Giới thiệu

**@nlpgroup/ios-ui** là bộ thư viện thiết kế mã nguồn mở theo chuẩn **Apple Human Interface Guidelines (HIG)**, xây dựng cho hệ sinh thái **NLP Group**.

## Hệ sinh thái NLP Group

| Lĩnh vực | Mô tả |
|---|---|
| ☀️ **NLP Energy** | Năng lượng mặt trời, BESS, EMS |
| ⚡ **NLP EV Charging** | Trạm sạc xe điện, CSMS, OCPP |
| 💻 **NLP Technology** | Phần mềm, ERP, CRM, IoT |
| 🤖 **NLP AI & Digital** | AI Agent, Automation, ML |
| 🌱 **NLP ESG & Carbon** | Tín chỉ carbon, Net Zero |

## Tính năng chính

- ✅ **Chuẩn Apple HIG** — pixel perfect, đúng thông số superellipse
- ✅ **Light / Dark mode** tự động qua `prefers-color-scheme`
- ✅ **CSS Variables** — Design Tokens dễ tuỳ biến
- ✅ **Framework-agnostic** — HTML, Vue 3, React, Laravel Blade
- ✅ **Zero JS** cho CSS-only components
- ✅ **Accessibility** — ARIA roles, keyboard navigation
