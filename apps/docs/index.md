# NLP Group iOS UI

**@nlpgroup/ios-ui** — Pure iOS Human Interface Design System for Web & Modern Frameworks

*Lightweight · Zero-drift · Token-driven*

---

## Giới thiệu

Bộ thư viện thiết kế theo chuẩn **Apple Human Interface Guidelines (HIG)**, xây dựng cho hệ sinh thái **NLP Group**:

- ☀️ Năng lượng xanh
- ⚡ Xe điện & Trạm sạc EV
- 💻 Công nghệ phần mềm
- 🤖 Trí tuệ nhân tạo
- 🌱 ESG & Carbon

## Tính năng

- ✅ Chuẩn Apple HIG — pixel perfect
- ✅ Light / Dark mode tự động
- ✅ CSS Variables (Design Tokens)
- ✅ Framework-agnostic (HTML, Vue, React, Laravel Blade)
- ✅ Zero JavaScript dependencies cho CSS-only components
- ✅ Accessibility (ARIA, keyboard navigation)

## Cài đặt nhanh

```bash
pnpm add @nlpgroup/tokens @nlpgroup/core
```

```html
<link rel="stylesheet" href="node_modules/@nlpgroup/core/dist/ios-ui.css" />
```
